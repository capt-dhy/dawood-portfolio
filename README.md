# Dawood Yusuf — Personal Portfolio

Personal portfolio for Dawood Yusuf Hassan, a software engineer, builder, and founder.

Live site: https://dawood-eta.vercel.app/

## About

The site presents Dawood's public work, technical skills, background, and contact information. It also introduces DHYTech as the company he founded.

## Tech

- HTML
- CSS
- JavaScript
- Responsive design
- Embedded project previews with iframes

## Development

This is a lightweight static site with no build step required. Open `index.html` locally or deploy the repository with a static hosting provider such as Vercel.
